# TargetList.md

TargetList 是一个用于显示和管理用户选择的操作目标（文件或目录）的组件。它允许用户添加、删除和修改操作目标，这些目标将被用于后续的文件扫描和重复文件识别操作。

## 界面描述


### 列表
* TargetList 组件位于全局主界面的左侧，显示一个列表，列出用户已选择的操作目标。每个目标项显示目标的路径和类型（文件或目录）。
* 列表是垂直排列的，通过 virtual list 技术实现高效渲染，确保在目标数量较多时界面仍然流畅。


### 列表项

* 每个列表项包含以下元素：
  * 目标名称 targetName：无论是文件还是目录，显示其名称包括扩展名。使用粗体无衬线字体，字号稍大，以突出显示。如果名称过长，超过列表项宽度，则缩小字号并换行显示，最多显示两行，末尾使用省略号表示被截断的部分。当 name 被截断时，鼠标悬停在目标名称上会显示完整路径的 tooltip。
  * 目标类型 targetType：显示目标是文件还是目录，或者是硬链接等特殊类型。使用图标显示在 targetName 右边。
  * 目标路径 targetPath：显示目标的完整路径，使用较小的字体显示在 targetName 下方，颜色较淡以区分层次。如果路径过长，超过列表项宽度，则缩小字号并换行显示，最多显示三行，末尾使用省略号表示被截断的部分。当 path 被截断时，鼠标悬停在目标路径上会显示完整路径的 tooltip。
  * 底部为一条彩色细线，高度 2px，宽度占满整个列表项，用于区分不同的目标项。
  * 当鼠标悬停在列表项上时，列表项底部，细线上方靠右位置会显示一个删除图标（垃圾桶），点击该图标可以删除该目标项。删除图标默认隐藏，只有在鼠标悬停时才显示。
  * 删除图标（垃圾桶）左边为一个放大镜图标，点击该图标可以在系统文件资源管理器中打开该目标项所在的目录，并选中该目标项。放大镜图标默认隐藏，只有在鼠标悬停时才显示。

### 列表底部操作区

* 列表底部有一个操作区，包含一个“添加目标”按钮和一个“清空列表”按钮。
* “添加目标”按钮：点击后会弹出一个系统文件选择对话框，允许用户选择一个或多个文件或目录作为新的操作目标。选择完成后，所选的目标将被添加到列表中。
* “清空列表”按钮：点击后会弹出一个确认对话框，询问用户是否确认清空列表。确认后，列表中的所有目标将被删除。

### 交互设计

* 用户可以通过点击列表项上的删除图标来删除单个目标项。
* 用户可以通过点击列表项上的放大镜图标来在系统文件资源管理器中打开目标项所在的目录，并选中该目标项。
* 用户可以通过点击“添加目标”按钮来添加新的操作目标，支持选择多个文件或目录。
* 用户可以通过点击“清空列表”按钮来删除列表中的所有目标项，但需要先进行确认以防止误操作。
* 当用户添加、删除或清空目标项时，界面会实时更新，反映当前的目标列表状态。同时，相关的操作按钮（如“清空列表”）会根据列表是否为空来启用或禁用，以提供更好的用户体验。
* 当用户将鼠标悬停在目标名称或路径上时，如果文本被截断，会显示完整路径的 tooltip，帮助用户查看完整信息。
* 当用户将鼠标悬停在列表项上时，显示删除和放大镜图标，提供快速操作选项，同时保持界面的简洁性。
* 用户在添加目标时，如果选择了已经存在于列表中的目标，界面会提示用户该目标已存在，并且不会重复添加。
* 用户在删除目标或清空列表时，如果该目标正在被扫描或处理，仍然可以进行删除操作，无须等待扫描完成。
* 用户可以通过从系统文件资源管理器中拖拽文件或目录到 TargetList 组件上来添加新的操作目标，支持同时添加多个目标。拖拽过程中，TargetList 组件会显示一个高亮的边框，提示用户可以放置目标。放置完成后，所拖拽的目标将被添加到列表中。
