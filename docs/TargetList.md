# TargetList.md — 目标列表

目标列表（`TargetList.vue`）是主界面左侧的常驻窗格（宽 280px，最小 220px），不受右侧 Tab 切换影响。它管理待扫描的文件/目录目标，并显示每个目标的扫描进度。

## 界面

- 顶部提示行：`拖入文件或目录，或点击下方按钮添加`；拖拽悬停时变为 `松开以添加目标`，整个窗格以强调色浅底 + 右侧分隔线变色提示可放置。
- 列表：虚拟滚动，格子定高 70px（外层 padding 承载面板间隙），内部为 64px Fluent 卡片面板：纯白底（暗色为主题表面色）、悬停 `--surface-hover`、4px 圆角；列表容器取消卡片形态，右侧一条竖向分隔线与内容区分隔。
- 列表项：
  - 名称（路径末段，粗体较大）；
  - 完整路径（较小、弱化色，超长省略，title 显示完整路径）；
  - 悬停时显示两个图标按钮：放大镜「在资源管理器中显示」（`fs:reveal`）、✕「移除目标」；
  - 面板底部内嵌独立进度条（3px 圆角短 pill，左右留空）：按该目标进度填充；扫描正常结束后保持满格，被取消则停在最后进度。
- 空列表显示「尚未添加扫描目标」。
- 底部操作区：`+` 添加目录（系统多选对话框，kind = both，可多选文件/目录）、清空按钮（trash 图标；空列表或添加对话框进行中禁用）。

## 交互与行为

- 添加：系统对话框选择，或从系统资源管理器拖拽文件/目录进入（`webUtils.getPathForFile` 取真实路径）；精确字符串去重，已存在的路径不会重复添加。添加顺序即列表顺序。
- 移除/清空：只从目标列表移除，**不删除任何文件**；清空需应用内确认对话框（「确认清空全部扫描目标？仅从列表移除，不删除文件本身。」）。
- 持久化：任何增删清空都写入 `settings.json` 的 `targets`；启动时恢复。
- 自动扫描：目标列表变化后 `App.vue` 监听并触发增量同步——新增目标枚举、移除目标纯内存清理（详见 [DupeSeek.md](./DupeSeek.md)「自动增量扫描」与 [Store.md](./Store.md) §5）。扫描进行中发生的变化记为挂起，本轮结束后补一轮。删除目标时即使正在扫描也可操作，无需等待。
- 清空全部目标会同步到引擎（全部目标移除，体积树与重复组随之清空），不只是清界面。
- 嵌套目标（父目录与子目录同时存在）由引擎做路径级去重与归属，列表本身不去重父子关系。

> 旧版「应用内拖拽」MIME（`application/x-dupeseek-path`）接收代码仍在，但产生方（浏览 Tab）已移除，现仅系统拖放生效。
