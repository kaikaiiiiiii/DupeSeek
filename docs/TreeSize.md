# TreeSize.md

空间分析视图（`TreeSizeView.vue`）位于主界面右侧功能区，通过 Tabs 切换显示（"空间分析" Tab）。v0.3 提供两种视图：**矩形树图**（`TreemapChart.vue`，默认）与**树形列表**（`TreeList.vue`），工具栏可切换。

## 数据来源

- 主进程扫描引擎在枚举阶段登记所有访问过的目录，文件体积沿祖先链累加到目标根（`ScanTreeNode.size`，含子孙聚合）。
- 重复占用 `dupWasted` 的归集口径：每个重复组保留**最早修改**的一份，其余副本的体积计入各自所在目录链。该口径与 DupeList 默认选择器一致，但清理动作以 DupeList 的实际选择为准。
- 树在 `scan:done` 时随 `ScanSummary.tree` 一次性下发（多目标为森林），子级按体积降序。

## 矩形树图（treemap）

- **squarified 布局**（Bruls et al.）：面积 ∝ size，长宽比尽量接近 1；几何用 SVG `<rect>` 表达（坐标为 SVG 属性，非内联样式），容器尺寸经 ResizeObserver 测量，随窗口缩放重排。
- **着色**：按目录内重复占比分 5 档热力色（无重复 / <2% / 2–5% / 5–10% / ≥10%），底部有图例。
- **交互**：点击含子目录的瓦片下钻，顶部面包屑回退；单根树初始自动下钻一层；悬停 `<title>` 显示名称、体积、重复与子目录数。
- **碎片聚合**：单层子目录超过 14 个时，小于总量 0.4% 的归入"其他 N 项"瓦片（不可下钻）。
- 文本标签经 `<clipPath>` 裁剪，小尺寸瓦片自动隐藏标签。

## 树形列表

- 摊平后的定高行（28px）走虚拟滚动：深度用不可见的 `indent-gap` 占位 span 表达；列依次为展开箭头、目录名、聚合大小、重复占用（无则 "—"）。
- 点击含子目录的行展开 / 收起（箭头 ▸/▾ 指示）；展开状态以路径为键存于 `useTreeSizeStore`，虚拟滚动复用行不影响状态；支持全部展开 / 收起。

## 生命周期

- 新一轮扫描开始时树重置；扫描结束后被新树替换，视图焦点随之复位。
