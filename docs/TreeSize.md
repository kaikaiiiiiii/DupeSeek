# TreeSize.md

空间分析视图（`TreeSizeView.vue`）位于主界面右侧功能区，通过 Tabs 切换显示（"空间分析" Tab）。v0.2 实现目录体积树；矩形树图（treemap）等可视化方式为后续迭代。

## 数据来源

- 主进程扫描引擎在枚举阶段登记所有访问过的目录，文件体积沿祖先链累加到目标根（`ScanTreeNode.size`，含子孙聚合）。
- 重复占用 `dupWasted` 的归集口径：每个重复组保留**最早修改**的一份，其余副本的体积计入各自所在目录链。该口径与 DupeList 默认选择器一致，但清理动作以 DupeList 的实际选择为准。
- 树在 `scan:done` 时随 `ScanSummary.tree` 一次性下发（多目标为森林），子级按体积降序。

## 界面设计

- 顶部统计条：目录总数、总大小、重复占用（有重复时红色高亮）；右侧"全部展开 / 全部收起"。
- 主体为**摊平后的定高行（28px）走虚拟滚动**：深度用不可见的 `indent-gap` 占位 span 表达，避免内联样式；列依次为展开箭头、目录名、聚合大小、重复占用（无则 "—"）。

## 交互逻辑

- 点击含子目录的行：展开 / 收起（箭头 ▸/▾ 指示）；叶子行无箭头。
- 展开状态以路径为键存于 `useTreeSizeStore`，虚拟滚动复用行不影响状态。
- 新一轮扫描开始时树重置；扫描结束后被新树替换。
