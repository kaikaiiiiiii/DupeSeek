# TreeSize.md — 空间分析视图

空间分析（`TreeSizeView.vue`）位于主界面右侧功能区，是默认标签页（Tabs 切换见 [Tabs.md](./Tabs.md)）。当前只有**树形列表**一种视图（`TreeList.vue`）；旧设计的矩形树图（TreemapChart）已废弃。

## 布局组成

- 工具栏（`TreeSizeView.vue`）：`N 个目录 · 总大小 X · 重复占用 Y`（重复占用 >0 时危险色）+「全部展开」「全部收起」按钮（无数据/无展开时禁用）。
- 表头（`TreeList.vue`）：`名称 / 大小 / 重复占用` 三列，点击列切换排序（再点同一列反向）。名称排序默认升序，大小/重复默认降序，当前排序列显示 ↓/↑。大小列与重复列右缘有拖拽手柄，可横向调整列宽（60–320px，默认 100/110px），列宽经 CSS 变量同时驱动表头、行与体积条几何。
- 数据行：定高 34px，虚拟滚动（`VirtualScrollList`），缩进 16px/层。每行：展开箭头（可展开时）、行内系统图标、左侧内联体积文本、名称（超长省略，title 显示完整路径）、大小、重复占用（无则「—」）。
- 加载：子级数据在途时插入定高骨架行（shimmer），不做文字提示；无数据显示「左侧添加扫描目标后自动开始分析」（扫描中显示「正在扫描，体积树将在扫描完成后生成…」）。

## 数据来源与拉取协议

- 权威数据在主进程扫描引擎（`dirs` / `childDirs` / `dirFiles` 索引），渲染层只发查询：
  - `tree:roots(sortKey, desc)` → 根级行（每个已同步目标一行）+ 全局 `stats`；
  - `tree:children(dir, sortKey, desc)` → 子目录行 + 可选直属文件聚合行（目录同时有子目录与直属文件时才有 `agg`；只有子目录时无聚合行；无子目录的目录**不返回聚合**，前端展开后直接列直属文件）；
  - `tree:files(dir, sortKey, desc, offset, limit)` → 直属文件分页（前端一次取 10000 条）；
  - `tree:stats(path)` → 分支统计（见 [Cleanup.md](./Cleanup.md)）。
- 目录行携带元数据（`childDirs` / `fileCount` / `fileBytes`），前端无需二次请求即可画展开箭头与 `[n 个文件]` 占位。
- 缓存与版本：`useTreeSizeStore` 只缓存已展开路径；收到 `ScanProgress.treeRev`（扫描中）或 `scan:rev` 广播（移除目标、分支刷新等）后 400ms 尾沿节流失效并重取已展开路径（stale-while-revalidate：旧数据保留显示，响应到达后原位覆盖）。响应 `rev` 小于当前版本视为过期丢弃。
- 展开状态按「位置」记键：同一目录作为嵌套目标根行、又作为父目标树中的子行出现时是两个独立 UI 条目，展开互不联动；数据缓存仍按路径共享。

## 树形列表交互

- 点击目录行：有子级（`childDirs > 0 || fileCount > 0`）才可展开/收起；无子级目录为叶子行。
- `[n 个文件]` 聚合行：可展开为逐文件条目（与该层同序规则）；名称排序时聚合行恒排该层末尾。
- 文件行：目录无子目录时直接展开列出；聚合展开时列出。文件行为叶子，不可展开。
- 行内图标（`TreeIcon.vue` → 主进程图标服务）：文件用 `getFileIcon`（large 32px 源）；目录优先读 desktop.ini 自定义图标（仅指向图片文件时），否则用内置文件夹图标（本 Electron 版本 `getFileIcon` 对目录返回「存储设备」，盘根除外）；聚合行用内置图标；取图标失败回退内置 folder/file 图标。渲染层按 120ms 合批请求、只请求可见行，主进程带 path → dataURL 缓存。
- 全部展开只展开「已加载缓存内」的条目（懒加载下数据随展开逐步取回）；全部收起清空展开状态。

## 体积与重复口径

- `大小` = 该目录（含子孙）聚合文件字节数；`重复占用` = 该目录（含子孙）中作为非保留副本被计入的字节数。
- 每个重复组保留 **mtime 最早**的一份作为「保留」，其余副本的体积计入各自目录链（与 DupeList 默认选择器语义一致，但清理动作以用户实际勾选为准）。
- 压缩包内容在树中呈现为 `容器路径::` 合成目录链；包内条目体积只累加到合成根，不进入真实目录（包文件本身按压缩后体积计入所在目录）。合成节点不计入「目录数」统计。
- 全局 `stats`（工具栏）为渲染层条目并集口径（嵌套目标重叠部分只计一次）：`totalSize` = 全部条目体积和——**含压缩包内条目体积，同时容器文件本身也计入**，因此压缩包较多时该值会高于磁盘占用；`totalDup` = Σ size×(成员数−1)；`dirCount` = 后端目录节点数（含 `容器::` 合成节点与排除空节点）。

## 行右键菜单

（聚合行不提供；`容器::` 合成节点当前**未屏蔽**，属已知缺口，见 [Cleanup.md](./Cleanup.md)「已知缺口」）

| 菜单项 | 适用 | 行为 |
| --- | --- | --- |
| 清理该位置重复文件 | 目录 / 文件 | 应用 `underPath(path)` 范围规则并切到清理规则页；该位置无重复时禁用 |
| 更新该分支 | 目录 | 引擎 `refreshBranch` 单独重遍历该子树并比对，不改变目标列表 |
| 在资源管理器中打开 | 目录 / 文件 | 目录系统打开；文件定位到所在文件夹 |
| 统计数据 | 目录 | 打开 `StatsPanel` 分支统计弹窗 |

菜单实现为 `ContextMenu.vue`（Teleport + 视口边缘收敛 + Esc 关闭），统计弹窗为 `StatsPanel.vue`。

## 生命周期

- 新增目标：目标根行立即以空树出现，随枚举实时生长（扫描期间版本号持续推进）。
- 移除目标：根行即时消失，后台分批清理；渲染层经 `scan:rev` 跟随重取。
- 分支刷新：刷新结束后 `rebuildDirs` 推进版本号，树按 `scan:rev` 重取。
- 新一轮「重新扫描」：`treesize.reset()` 清空缓存与展开状态后重取根级。
