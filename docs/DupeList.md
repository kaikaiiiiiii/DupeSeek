# DupeList.md — 清理规则视图

清理规则视图（`DupeList.vue`）位于主界面右侧功能区，Tabs 标签为「清理规则」（见 [Tabs.md](./Tabs.md)）。本页展示重复文件组，并提供筛选、批量选择与清理执行。选择语义与不变量见 [Cleanup.md](./Cleanup.md)。

## 工具栏

- 左侧统计：`共 N 组 · 可释放 X`——N 为**筛选后可见组数**；可释放 X 为全部组的 Σ 组大小 ×(成员数−1)，不受筛选影响。
- 保留规则选择器（`KeepRule`）：`每组保留首个 / 每组保留最早的 / 每组保留最新的 / 每组保留路径最短的`，点「应用选择器」后：每组挑出保留件，**自动反勾同组其余普通条目**（即勾选待清理），同时清除当前范围规则。只作用于当前可见（筛选后）的组。
- 「删除勾选（进回收站）」按钮：勾选数为 0 时禁用。

## 范围规则提示条

当空间分析行右键「清理该位置重复文件」应用了 `underPath` 范围规则时显示：彩边 info-bar，文案 `范围规则：仅勾选 <路径> 下的文件（N 项）`，右侧 ✕ 清除规则并清空勾选。规则激活期间勾选集按规则重算（手动勾选仍可改）。

## 筛选行

- `扩展名筛选`：如 `.jpg`，大小写不敏感，组内任一条目命中即显示。
- `路径包含…`：子串匹配组内任一条目路径。
- `最小 MB`：按组大小过滤（输入为空或 ≤0 不过滤）。

**注意**：选择器与「删除勾选」只作用于筛选后的可见组，但勾选集本身跨全部组；有筛选时确认弹窗中的删除数量以实际计划为准。

## 列表

定高 30px 行，虚拟滚动（`VirtualScrollList`）。内容：

- 组头行：折叠箭头（chevron，可收起/展开该组）、组标题（取组内首个条目的文件名）、`N 个文件 · 大小`、`勾选 x / y`（y = 普通条目数，压缩包内条目不计）。
- 条目行：
  - 普通文件：方形 checkbox（勾选填充强调色 + ✓），路径，修改时间（`yyyy-MM-dd HH:mm`；取不到显示「—」）；勾选行文字用危险色提示「待清理」。
  - 压缩包内条目：显示 box 图标、`readonly` 样式、不可勾选；title 提示「压缩包内条目仅参与查重，不参与清理」。
  - 点击整行切换勾选（仅普通文件）。
- 无重复时显示「暂无重复文件，先到「扫描参数」页运行一次扫描」。

## 清理流程

1. 点「删除勾选」→ `planClean()` 计算：遍历可见组，收集勾选的普通条目；
2. **范围外存活才删**：一组内全部普通条目都被勾选时整组跳过（避免删光一组副本），跳过组数在确认弹窗中预告；
3. 确认弹窗（应用内 Fluent 对话框，Esc 取消）：`确认把 N 个勾选文件移入回收站？（另有 M 组将整组跳过：全部副本都在勾选范围内，删光会丢失文件）`；
4. 确认后 `clean:run` → 主进程逐个 `shell.trashItem` 进回收站，返回 `{ ok, failed, freedBytes }`；
5. 成功项从列表移除、失败项保留，不足 2 个成员的组解散；页面显示 `已清理 N 项，释放 X（M 项失败）`。

**已知限制**：`CleanAction.keepPaths` 会随请求发送但主进程当前未读取（为硬链接/合并移动预留）；硬链接、合并移动两种清理方式尚未实现（见 [DataModel.md](./DataModel.md) §6）。
