# 数据结构与计算逻辑

## 扫描过程

对于扫描到的每一个普通文件，应当包括如下信息：

| 变量名   | 类型   | 描述                   | 必须 | 示例                       | 备注                                     |
| :------- | :----- | :--------------------- | :--- | :------------------------- | :--------------------------------------- |
| name     | string | 文件名（含扩展名）     | y    | filename.txt               |                                          |
| path     | string | 文件路径               | y    | /path/to/file              |                                          |
| size     | number | 文件大小               | y    | 159382                     |
| class    | string | 文件类型（扩展名含\.） | y    | .txt                       | 当文件本身没有扩展名时，使用空字符串 ""  |
| mtime    | number | 文件最后修改时间       | y    | 173203485xxxx              | 默认值为 0，即1970-01-01 00:00:00        |
| crc32    | number | 文件 crc32 值          | n    |                            |
| headmd5  | string | 文件头部 md5 值        | n    |                            |
| fullmd5  | string | 文件 md5 值            | n    |                            |
| fullpath | string | 用于显示的文件完整路径 | y    | /path/to/file/filename.txt | 对于压缩包，需要进一步包含解压路径与文件 |

算法在扫描到文件时，仅记录 name path size mtime 等可以直接从 fs.lstat 获取的信息，并同时和已保存的数据进行比对。如果发现有相同名称、大小或其它根据用户设置规则下发现的重复文件，则进一步对两个文件都进行 headmd5 计算，如果不同，则认为是独立文件。如果相同，则进一步计算 fullmd5，如果不同则认为是独立文件。如果相同，则最终认定是重复文件。

* 根据用户设置，扫描目录目录下的所有文件。
  * 如果是目录，继续递归扫描。
  * 如果是 mklink 的软链接，根据用户设置确定处理逻辑。并且要判断是否可能与其它目录构成无尽循环，是则跳过。
  * 如果是文件，首先记录 name path size mtime 等fs.lstat信息。

* 遇到两个文件有相同的 size / 或 size+name（根据用户设置），疑似相同时。
  * 计算两个文件的 headmd5，并保存到两者各自的对象键值中。
  * 如果 headmd5 不同，则认为是独立文件。
  * 如果 headmd5 相同，则计算 fullmd5。
  * 如果 fullmd5 不同，则认为是独立文件。
  * 如果 fullmd5 相同，则认为是重复文件。
  
* 遇到可识别的压缩包（zip/rar/7z 等）
  * 将压缩包本身作为普通文件处理。记录 name path size mtime 等fs.lstat信息，疑似相同时进一步计算 headmd5，仍疑似相同时进一步计算 fullmd5。
  * 通过扩展库读取
