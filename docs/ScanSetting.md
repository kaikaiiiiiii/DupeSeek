# ScanSetting.md

扫描设置组件（ScanSettings.vue）位于 DupeSeek 主界面功能区右侧下方，通过 Tabs 组件切换显示。

以下描述的方便均为 ScanSettings.vue 自身的位置，不涉及布局容器包裹外的位置。

## 界面设计

扫描设置组件为一个垂直布局组件，分为上下两部分：

上部是一个表单区域，包含多个输入项和选项，用于配置重复文件扫描的相关参数。用户可以在这里设置要扫描的目录路径、文件类型过滤器（例如，只扫描特定扩展名的文件）、是否包含隐藏文件等选项。

下部是一个操作区域，包含一个“开始扫描”按钮，用户点击后会根据上部设置的参数启动重复文件扫描过程。

### 扫描设置表单

当表单高度过长时，表单区域显示滚动条。

表单选项如下：（ [] 表示 checkbox，<> 表示 input）

[] 排除隐藏文件 - 是否在扫描过程中排除隐藏文件。
[] 排除系统文件 - 是否在扫描过程中排除系统文件。
[] 排除小于 <输入框+下拉框> 文件：
    用户可以输入一个文件大小阈值（例如，10MB），表示在扫描过程中排除小于该大小的文件。下拉框用于选择大小单位，包括 Byte，KB、MB、GB 四项。
[] 排除大于 <输入框+下拉框>文件：
    用户可以输入一个文件大小阈值（例如，1GB），表示在扫描过程中排除大于该大小的文件。下拉框用于选择大小单位，包括 Byte，KB、MB、GB 四项.
[] 文件类型黑名单：用户可以输入要排除的文件扩展名列表，扩展名之间用逗号分隔。例如，输入 "exe,dll" 表示排除 exe 和 dll 格式的文件。
[] 文件类型白名单：用户可以输入要包含的文件扩展名列表，只扫描特定扩展名的文件。
黑名单和白名单选项可以同时使用，扫描时会先根据黑名单排除文件，再根据白名单筛选文件。

[] 相同文件名 [] 相同扩展名
[] 相同修改日期 []相同创建日期
[] 排除 junction point 文件（默认钩选）

### 启动按钮

当用户点击“开始扫描”按钮时，组件会将表单中设置的参数传递给后端，启动重复文件扫描过程。而扫描的 target 列表，则通过 TargetList 组件进行管理和显示，用户可以在 TargetList 中查看和修改扫描的目标目录或文件列表。扫描过程中，组件会显示扫描进度和状态信息，帮助用户了解扫描的进展情况。

开始扫描按钮将变为“停止扫描”按钮，用户可以点击来中止正在进行的扫描过程。扫描完成或中止后，按钮将恢复为“开始扫描”按钮。
