# Cleanup — 清理范围规则与分支操作

清理从「每组保留一件」演进为「勾选待清理 + 范围规则」。本文档定义架构与不变量。

## 范围规则（ScopeRule）

带参数的只读规则对象，描述「哪些文件被勾选」：

```ts
interface ScopeUnderPathRule { kind: 'underPath'; path: string }  // 只选择该目录路径下的文件
type ScopeRule = ScopeUnderPathRule
```

**两段逻辑**（架构约束）：

1. **规则定义**：`dupe.applyScopeRule(rule)` 把规则登记进 store 并据此重算勾选集——
   规则本身是纯数据，不含任何 UI 动作；
2. **规则应用**：入口（空间分析右键菜单等）= 构造规则对象 + 调用 `applyScopeRule`
   + 切到清理规则页。新增入口（如未来「按扩展名圈范围」）只需扩展 ScopeRule
   种类，不新增动作通路。

勾选语义：**勾选 = 待清理**（删除候选），不是保留标记；与「范围外存活才删」
不变量配套。

## 不变量

- 压缩包内条目（containerPath ≠ null）永不进入勾选集，也不进入删除清单；
- **范围外存活**：一组内全部普通条目都被勾选时，执行清理整组跳过——该组
  不存在范围外存活副本，删光会丢失文件；跳过组数在确认弹窗预告；
- 手动勾选/取消即时生效；范围规则重新应用时勾选集重置为规则计算结果。

## 空间分析右键菜单

TreeList 行右键（聚合行不提供）：

| 菜单项 | 适用 | 行为 |
| --- | --- | --- |
| 清理该位置重复文件 | 目录 / 文件 | 应用 `underPath(path)` 规则并切到清理规则页；该位置无重复时禁用 |
| 更新该分支 | 目录 | 引擎 `refreshBranch`：单独重遍历该子树并比对，不改变目标列表 |
| 在资源管理器中打开 | 目录 / 文件 | 目录 `shell.openPath`；文件定位到所在文件夹（showItemInFolder） |
| 统计数据 | 目录 | 打开统计面板（体积/数量 + k-means 大小分布直方图） |

## 更新该分支（refreshBranch）

动机：用户拿到重复清单后可能在应用外手工增删文件，需要对单个子树重扫——
而非整盘重扫，也不把它加进目标列表。

流程：定位最深覆盖目标 → es `-path` 子树枚举（不可用回退 fs walk）→ 与会话内
该前缀条目 diff：新增登记 / 消失删除（组随之剔除）/ 变化更新（mtime 或体积变
即清空哈希重算）→ 新容器重列包内条目 → 触碰桶重哈希 → `rebuildDirs` 全量
重算体积树。

- 按**当前扫描参数（草稿）**执行，可能与整盘当时的口径不同（文档化行为）；
- 执行期与其它扫描互斥（running 互斥）；组经 scan:group 增量到达，树经
  scan:rev 实时更新（渲染层对刷新期组事件放行）。

## 统计数据口径

- 总体积：树节点聚合值（含子树；已解析压缩包按包内未压缩内容计，与树显示一致）；
- 总文件数：递归真实文件 + 包内条目；总文件夹数：真实目录（不含 `容器::` 合成节点）；
- 平均每文件体积 = 总体积 / 总文件数；
- 大小分布：对上述文件大小做 1D k-means（k = min(10, 不同大小档数)，分位数
  种子 + Lloyd 迭代，空簇按全局分位重播种），返回各组中心与成员数，
  前端渲染 ≤10 柱直方图。
