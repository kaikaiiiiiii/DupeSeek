# Explorer.md

浏览器组件（Explorer.vue）位于 DupeSeek 主界面功能区右侧下方，通过 Tabs 组件切换显示。

以下描述的方便均为 Explorer.vue 自身的位置，不涉及布局容器包裹外的位置。

## 界面设计

### 界面布局

浏览器组件为 一个垂直布局组件，分为顶部，上部、下部和底部四部分。

顶部是一个文字路径，以 breadcrumb 的形式展示当前浏览的目录路径，用户可以点击路径中的任意部分来快速跳转到对应的目录。

* 上部预置与收藏目录文件项列表

上部是一个框，里面放有若干个预置与收藏目录项，用户可以点击这些目录文件项来快速浏览到对应的目录或文件。预定义的目标文件项包括：

windows 下的：桌面、文档、下载、C:盘、D:盘等盘符。
macOS 下的：桌面、文档、下载、应用程序、用户根目录。
linux 下的：桌面、文档、下载、用户根目录等。

同时允许用户自定义添加收藏的目录文件项，用户可以通过下文描述的操作添加到这里。

目录文件项是一个固定长宽的组件，因此在框内的排列是先从左到右，满一行后换行继续排列。

* 下部
  
  下部是当前目录下的所有文件和子目录的列表。由于子目录与文件可能数量众多，列表需要使用 virtual list 技术来高效展示。和 windows 下的资源管理器类似，列表需要显示每一项的图标、名称、修改日期、类型和大小（目录不用显示大小）。

底部为一个 input 输入框，用户可以在直接输入要扫描的目录路径，input 框内右侧有一个回车按钮。

### 预置与收藏目录项 favorite item

预置与收藏目录项是一个有固定高度、最大最小宽度限制的半自适应组件，其宽度会根据 explorer.vue 组件的宽度进行调整，类似于 bootstrap 中的栅格。

每个项目包含一个图标和一个文字标签，图标显示该目录或文件的类型（例如，文件夹、硬盘等），文字标签显示目录或文件的名称。

### 当前目录下的文件和子目录条目 simple item

与 windows 资源管理器类似，当前目录下的文件和子目录条目是一个最简单的长条形组件，如果是目录，显示目录图标和名称；如果是文件，显示文件图标和名称。
