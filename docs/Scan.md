# Scan.md — 扫描参数视图

扫描参数视图（`ScanView.vue`）位于主界面右侧功能区，通过 Tabs 切换显示（标签名「扫描参数」，见 [Tabs.md](./Tabs.md)）。页面分上下两张卡片：扫描选项表单与运行区。

## 扫描选项表单

垂直表单，可滚动。字段与标签如下：

| 控件 | 语义 |
| --- | --- |
| `忽略文件名（仅按大小分组）` | 对应 `ignoreName`；勾选后 L0 分桶只按大小 |
| `排除隐藏文件` | 排除**点前缀名**（`.xxx`），不读取 Windows 隐藏属性 |
| `排除系统文件` | 排除已知系统目录名（`$RECYCLE.BIN` / `System Volume Information` / `WindowsApps`） |
| `排除 junction / 链接目录（防循环）` | 对应 `excludeJunction`，默认勾选；跳过 reparse 子树 |
| `排除小于` | 勾选后启用「数值 + 单位（KB/MB/GB）」输入；换算为字节阈值（含边界） |
| `排除大于` | 同上，默认单位 GB |
| `扩展名黑名单` | 逗号分隔（支持中英文逗号与空白），自动去前导点、转小写 |
| `扩展名白名单` | 留空表示不限制；非空时仅保留命中项，先黑后白 |
| `排除的目录名` | 逗号分隔；任意层级同名目录按空节点呈现（默认 `node_modules`） |
| `排除的目录路径` | 逗号分隔绝对路径；该目录整棵子树按空节点呈现 |

- 压缩包内容解析开关（`scanArchives`）与 Everything 枚举开关（`useEverything`）**不在本页**，位于「软件设置」页（见 [Settings.md](./Settings.md)）。
- 大部分选项直接绑定 `useScanStore().draft`；大小阈值与扩展名列表使用本地输入状态，开始扫描时换算/解析回 draft 并随请求快照传给主进程。
- 无「相同文件名/扩展名/修改日期/创建日期」多选；仅 `ignoreName` 一个分组开关（日期只作展示，不参与分组）。

## 运行区

- 按钮：非扫描中显示「重新扫描（N 个目标）」（N = 当前目标数，0 时禁用）；扫描中变为「停止扫描」（协作式取消，已算出结果照常回流）。
- 进度（仅扫描中）：Fluent 细进度条（`<progress>`，6px）+ 阶段标签（正在枚举文件 / 正在比对哈希 / 正在收尾）+ 百分比 + 已用时计时 + `候选数 · 已哈希字节` + 当前路径（超长省略，title 显示全路径）。
- 提权提示（`denied > 0` 且扫描中或已结束时常驻）：彩边 info-bar，文案 `有 N 个文件或目录需要管理员权限才能读取`，按钮「以管理员身份重启并重新扫描」→ `app:elevate`；UAC 取消时提示「未获得授权」。提权成功后主进程保存 `resumeScan` 标记退出，管理员实例启动后自动续扫。
- 完成汇总（`status === 'done'`）：`完成：N 个文件，M 组重复，可释放 X，耗时 s 秒`；被取消标注「（已取消）」；有读取失败/权限不足时追加条数。
- 出错（`status === 'error'`）：危险色 info 条显示 `scan.error`。

## 行为说明

- 目标增删会在 `App.vue` 监听后自动触发增量同步（新增枚举+触碰桶比较，移除纯内存清理），**不需要**在本页点按钮；本页按钮是「清空会话后全量重扫」。
- 扫描设置（扫描选项、开关）在下一轮同步/扫描时生效；设置页的两个开关改动即时持久化、不打断进行中的扫描。
- 扫描期间目标变化被记为挂起，本轮结束后自动补一轮增量同步（见 [Store.md](./Store.md) §5）。
- 进度百分比为条目计数口径（已处理 / 已发现），不是字节权重；总耗时由前端计时器按开始时间戳累计（切 Tab 不受影响）。
