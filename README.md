
DupeSeek 是一个查找重复文件的工具，支持多种策略来识别和处理重复文件。以下是 DupeSeek 的设计概述：


## 1. 文件扫描

DupeSeek 使用递归方式扫描指定目录及其子目录中的所有文件。用户可以选择要扫描的目录，并设置文件类型过滤器（例如，只扫描特定扩展名的文件）和其它扫描选项（例如，是否包含隐藏文件）。

## 2. 重复文件识别

DupeSeek 主要通过 md5 哈希算法来识别重复文件。对于每个文件，DupeSeek 计算其 md5 哈希值，并将哈希值与文件路径存储在一个哈希表中。如果发现相同的哈希值，则认为这些文件是重复的。

## 3. 结果展示

扫描完成后，DupeSeek 会将重复文件分组展示给用户。每个组包含具有相同 md5 哈希值的文件列表。用户可以查看每个文件的详细信息（例如，文件大小、修改日期等）来帮助他们决定如何处理这些重复文件。

## 4. 重复文件处理

DupeSeek 提供多种处理重复文件的选项，包括：
- 删除：用户可以选择删除重复文件中的一个或多个副本。
- 硬链接：用户可以选择将重复文件替换为硬链接，以节省磁盘空间。
- 合并移动：将所有多份文件移动到一个指定的目录中，且仅保留一份，并生成一份恢复 log。这种方式适合于特定的场景，例如共享一部分材料的多个不同方案要归档。

## 5. Treesize 可视化

DupeSeek 还提供了类似于 TreeSize 的可视化功能，帮助用户更直观地了解磁盘空间的使用情况。用户可以查看每个目录和文件占用的空间，并识别哪些目录包含大量重复文件。

## 6. 扩展功能

未来，DupeSeek 设想添加更多功能，例如：
- 支持压缩包内文件的扫描和重复识别。
- 更多的重复文件清理策略。
- 支持为特定文件开启 ntfs 透明压缩以降低真实占用。
